# Создай упрощенную версию с более простым управлением конфигурацией и структурой проекта. Это включает

_prev_main - тут прошлая версия с неудобной пробросом URL, API
python -X utf8 - указываем явно кодировку для Windows terminal
URL, API - могут быть внешними облаком так и локальным Docker, поэтому может API быть не указано для локального Docker.

python - тут будет новый проект расположен
python\.config\config.json - настройки
python\.config\config.example.json
python\.config\config.yaml - параметры для коллекций

Переменные окружения для URL и API ключа (проще чем файлы конфигурации)
Абсолютные импорты без проблем с относительными путями
Простые команды запуска без сложной структуры каталогов

GitHub-готовую структуру с .gitignore и примерами конфигурации
Предлагаю создать:

qdrant_fixer.py - единый скрипт для исправления
