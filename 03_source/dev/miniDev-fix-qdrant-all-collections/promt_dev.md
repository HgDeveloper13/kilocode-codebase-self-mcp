# 🚀 Промпт для разработки Qdrant Manager

## 📋 Описание проекта

**Qdrant Manager** - упрощенная система для управления и оптимизации коллекций Qdrant, разработанная с фокусом на массовое исправление `indexing_threshold` для улучшения производительности векторного поиска.

### Архитектурные принципы

- **Простота** - минимальная сложность с максимальной функциональностью
- **Надежность** - безопасные операции с поддержкой dry-run режима
- **Кроссплатформенность** - поддержка Windows/Linux/Mac
- **Конфигурируемость** - настройка через переменные окружения
- **Отчетность** - автоматическая генерация детальных отчетов

### Ключевые скрипты

#### qdrant_fixer.py
**Назначение**: Массовое исправление indexing_threshold для всех коллекций

**Основные возможности**:
- Автоматическое исправление indexing_threshold на значение 1
- Настройка vacuum_min_vector_number = 100
- Поддержка dry-run режима для безопасного тестирования
- Интерактивный и автоматический режимы работы
- Генерация детальных отчетов о результатах

**CLI интерфейс**:
```bash
python qdrant_fixer.py [--url URL] [--api-key API_KEY] [--threshold THRESHOLD] [--dry-run] [--auto]
```

#### qdrant_status.py
**Назначение**: Проверка и анализ статуса всех коллекций

**Основные возможности**:
- Получение подробной информации о всех коллекциях
- Анализ indexing_threshold значений
- Выявление коллекций, требующих исправления
- Генерация отчетов с рекомендациями
- Поддержка различных форматов вывода

**CLI интерфейс**:
```bash
python qdrant_status.py [--url URL] [--api-key API_KEY] [--output OUTPUT] [--quiet] [--threshold THRESHOLD]
```
