# ✅ ЧЕК-ЛИСТ ДЛЯ ПОЛЬЗОВАТЕЛЕЙ QDRANT MANAGER

## 🚀 Быстрый старт (5 минут)

### Шаг 1: Подготовка окружения
- [ ] Установлен Python 3.7+ 
- [ ] Склонирован репозиторий или скачаны файлы
- [ ] Перешли в папку `python/`

### Шаг 2: Установка зависимостей
- [ ] Установлены зависимости: `pip install -r requirements.txt`
- [ ] Проверка: `python test_imports.py` (должно показать ✅)

### Шаг 3: Настройка подключения
- [ ] Скопирован `.env.example` в `.env`
- [ ] Заполнен `QDRANT_URL` в файле `.env`
- [ ] Заполнен `QDRANT_API_KEY` (если требуется)

### Шаг 4: Тестирование подключения
- [ ] Запуск: `python qdrant_status.py --quiet`
- [ ] Должно появиться сообщение об успешном подключении

### Шаг 5: Проверка коллекций
- [ ] Полный статус: `python qdrant_status.py`
- [ ] Проверены отчеты в папке `reports/`

### Шаг 6: Исправление (при необходимости)
- [ ] Тестовый режим: `python qdrant_fixer.py --dry-run`
- [ ] Реальное исправление: `python qdrant_fixer.py --auto`
- [ ] Проверка результата: `python qdrant_status.py --quiet`

## 🔧 Альтернативные способы запуска

### Windows
- [ ] Проверка статуса: `run_status.bat`
- [ ] Исправление: `run_fix.bat`
- [ ] Автоматическое исправление: `run_fix.bat --auto`

### Linux/Mac
- [ ] Проверка статуса: `./run_status.sh`
- [ ] Исправление: `./run_fix.sh`
- [ ] Автоматическое исправление: `./run_fix.sh --auto`

## 📊 Контрольные точки

### После настройки должны работать:
- [ ] `python qdrant_status.py` - показывает список коллекций
- [ ] Создается файл отчета в `reports/`
- [ ] Отображается правильное количество векторов
- [ ] Показывается текущий `indexing_threshold`

### После исправления должны измениться:
- [ ] Все коллекции имеют `indexing_threshold = 1`
- [ ] Процент индексации увеличился
- [ ] Создан отчет об исправлении в `reports/`

## ⚠️ Решение проблем

### Если не подключается к Qdrant:
- [ ] Проверен URL в `.env` файле
- [ ] Qdrant сервис запущен и доступен
- [ ] Проверены firewall/порты

### Если ошибка аутентификации:
- [ ] Проверен `QDRANT_API_KEY` в `.env`
- [ ] Ключ действителен и имеет права доступа

### Если коллекции не найдены:
- [ ] Проверены права доступа к коллекциям
- [ ] Проверен пользователь/ключ API

### Если скрипты не запускаются:
- [ ] Установлен Python: `python --version`
- [ ] Установлены зависимости: `pip install -r requirements.txt`
- [ ] Проверены права на выполнение shell скриптов: `chmod +x *.sh`
